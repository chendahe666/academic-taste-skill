# 品味画像模板（01_taste_profile.md）

## 怎么从卡片走到规则

1. **合并档位**：打开 `raw/intros/key.json`，给每张卡补上档位。分成两组做对比：
   - 高档：award、oral、spotlight、highcite、poster_highcite
   - 低档：poster、rejected（withdrawn 单独看，撤稿原因多样）
   `poster_highcite` 也可以单独和 `poster` 比："同样是 poster，后来被引多的那些有什么不同"。
2. **计数表**：每个分类字段（idea 来源 A、gap 类型 B、开头 C、叙事步骤 D 里是否出现 ROOT-CAUSE / OBSERVATION / SCOPE、洞见所在段落、Figure 1 类型 E、强度 F、贡献是否可检验、有无 insight 句……）各做一张"高档 vs 低档"的表，写成 `x/N_high vs y/N_low`。
3. **规则强度**：
   | 强度 | 条件 |
   |---|---|
   | 强 | 高低档比例差 ≥ 30 个百分点，且高档至少 5 篇例证，且评审意见（若有）也支持 |
   | 中 | 差 ≥ 20 个百分点，或者比例差不大但评审意见明确支持 |
   | 弱 | 看得到趋势，但篇数太少（每档差不到 3 篇） |
   | 假设 | 只在 award / 范例里看到，或只来自 priors.md、没有被语料检验 |
4. **找反例**：每条规则至少找一篇"高档但没这样做"或"低档但这样做了"的论文，说明规则的边界。
5. **盲猜准确率**：把卡片里的盲猜和真实档位对一下，算出"仅凭 introduction 猜对高/低档"的比例。接近 50% 说明这个领域里 introduction 的写法区分度不高，结论要更保守，差距更多在实验和结果上。

## 模板

```markdown
# <领域> 的学术品味画像

## 0. 元信息
- 领域 / 子方向：
- venue 与年份：
- 语料：共 N 篇；各档篇数：award _, oral _, spotlight _, highcite _, poster_highcite _, poster _, rejected _
- 本话题在各 venue 的档位分布（来自 corpus.md）：例如 ICLR 2025 共 137 篇，oral 3、spotlight 6、poster 47、被拒 25、撤稿 56
- 评审意见：有 / 无（有多少篇）
- 盲猜准确率（仅凭 introduction 分高低档）：_ / _
- 生成日期；总体置信度：高 / 中 / 低

## 1. 一页纸：这个领域的 10 条品味
每条一行：规则 — 强度 — 证据计数 — 1–2 篇例证
R1. ...
...
R10. ...

## 2. 选题品味：这个领域奖励什么样的 idea
- idea 来源计数表（A1–A12 × 高/低档）
- 高档偏爱的来源类型，以及它们的典型形态（各配 2 篇例证、一句话说明）
- 低档常见的来源类型（尤其是"组合"类说不出为什么时）
- insight 性质：高档里"关于世界的论断"占比 vs 低档
- 真实来源旁证（来自 raw/origins.md）：作者自己讲的来历和 introduction 里讲的有什么不同
- 这个领域"疲劳"的选题或说法（审稿人已经看腻的）

## 3. 叙事品味：故事怎么讲
- 开头方式计数；洞见平均出现在第几段（高 vs 低）；具体问题第几段说清
- **标准叙事模板**（2–3 个，每个写成步骤序列 + 范例论文 + 什么情况下适用）
  例：模板甲 "现象先行"：¶1 CONTEXT → ¶2 OBSERVATION → ¶3 ROOT-CAUSE → ¶4 INSIGHT+APPROACH → ¶5 RESULT → CONTRIB（范例 P03、P11）
- Figure 1 惯例：类型计数，高档的 Figure 1 通常承担什么任务
- 贡献列表惯例：条数、类型、是否可检验
- 话说到多满：强度计数；"first / SOTA"措辞与档位的关系
- 篇幅与读者设定

## 4. 证据品味
- introduction 通常许诺哪些证据；高档许诺的和低档有什么不同
- 评审意见里反复出现的"审稿人认什么"（若有，附 forum 链接）

## 5. 反模式
每条：表现 — 在低档里出现几次 — 例证 — 评审原话（若有，短引）

## 6. 范例库
5–8 篇最值得精读的论文，每篇：为什么选它 + 值得偷的一招 + 链接

## 7. 时间漂移
较早年份和最近一年相比，什么变了（例如开始要求 scaling 实验、开始流行"surprisingly simple"叙事）

## 8. 局限与偏差
- 样本量和采样方式带来的限制
- 幸存者偏差：只看到了发表的和公开的被拒稿
- 引用数偏差：早发的、benchmark 类的论文天然高引
- 没有被拒档时：学到的是"好与更好"，不是"过与不过"
- 盲读不完美：已识别的论文有 _ 篇
```
